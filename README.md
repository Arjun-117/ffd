# VIT BFHL API Project

## GitHub Copilot - Claude Models Issue

**Problem**: Cannot see Claude Sonnet or Opus models in VS Code Copilot

**Solution**: See the complete setup guide: [COPILOT_CLAUDE_SETUP.md](./COPILOT_CLAUDE_SETUP.md)

### Quick Fix

1. **Verify Copilot Pro**: Go to [GitHub Copilot Settings](https://github.com/settings/copilot)
2. **Select Claude Model**: In GitHub settings, choose Claude 3.5 Sonnet as your model
3. **Update VS Code Extension**: Ensure GitHub Copilot extension is up to date
4. **Use Workspace Settings**: This repo includes `.vscode/settings.json` with Claude configuration

### Files Added

- `.vscode/settings.json` - VS Code settings for Claude models
- `.vscode/extensions.json` - Recommended extensions
- `COPILOT_CLAUDE_SETUP.md` - Complete troubleshooting guide
